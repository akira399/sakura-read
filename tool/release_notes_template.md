## 写作要点（自查清单）

- [ ] 标题形如 `樱读 vx.y.z ── 一句话亮点 🌸`
- [ ] **必写**，不能留空——用户就是靠这段了解更新内容
- [ ] 每条都在回答「**这对我有什么用**」，而不是罗列代码改动
- [ ] **不用表格 / 图片 / 嵌套列表**：弹窗里只会显示清洗后的纯文本
- [ ] 新功能、修复、变更**分开写**，用户扫一眼就知道该不该升
- [ ] 若修复了用户反馈的问题，**点名是哪个反馈**（用户会觉得被听见）
- [ ] 结尾保留合规声明
