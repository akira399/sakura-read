## 樱读 v1.1.0

### 下载

- APK：SakuraRead-v1.1.0.apk（arm64，约 34.7 MB）
- 系统要求：Android 7.0（API 24）及以上

### 新增

**发现页**

书架标题栏新增「发现」入口，按书源分类浏览书单。

- 支持 Legado 的 exploreUrl / ruleExplore 规则
- exploreUrl 格式：每行一个分类，写作「标题::地址」或「标题,地址」，
  地址支持 {{page}} 分页占位
- 同名分类跨书源并发抓取，结果按书名 + 作者合并

**离线缓存**

在线书籍详情页新增「缓存整本」。

- 逐章抓取并落盘，已缓存章节自动跳过，可断点续传
- 可随时暂停，未完成部分下次继续
- 显示已缓存章节数 / 总数与实时进度
- 支持清除单本缓存

**阅读排版扩展**

- 排版页新增「距顶部」「距底部」滑杆，调整正文上下留白（0–160）
- 「更多」页新增页眉、页脚独立开关
- 原「页边距」更名为「左右边距」

**EPUB 插图**

导入 EPUB 时提取正文引用的图片资源，存入书籍缓存目录。

- 滚动翻页模式下在正文中直接渲染插图
- 分页翻页模式保持「［插图］」文字占位（图片不参与分页测算）

### 变更

**发现页移至底部导航栏**

顶部入口由书架标题栏移至常驻底栏第四格，底栏由三格改为四格等宽。

- 支持两种 exploreUrl 写法：行格式 `分类名::地址`、JSON 数组
  `[{"title":"分类名","url":"地址"}]`
- 规则取值顺序：`ruleExplore.bookList` 优先，为空时回退 `ruleSearch`
- 使用 `@js:` 脚本生成分类的书源暂不支持（页面会说明）

**阅读器顶部工具条新增两个按钮**（在线书）

- **离线缓存**：一键缓存整本；下载中副标题显示进度条与「缓存 N/总数」，
  再点一次暂停；已缓存章节不重复下载
- **本章来源**：用系统浏览器打开当前章节原始网址；
  无可用浏览器时自动复制链接到剪贴板

### 修复

**朗读引擎兼容性**

部分机型自带语音引擎未被选为系统默认，导致朗读不可用。

- 设置页新增「朗读」区块：可枚举设备语音引擎、手动指定、播放测试语音
- 引擎初始化改为按序回退：指定引擎 → 系统默认 → 其余可用引擎
- 引擎选择结果持久化保存
- 原生层支持重建 TTS 实例，此前初始化失败后无法重试

### 其他

- 上下留白纳入分页布局参数，调整后自动重新分页
- 图片资源缺失或解码失败时降级为文字占位，不中断阅读
- 累计 270 项自动化测试通过，flutter analyze 无告警

### 说明

樱读是阅读工具，不提供、不分发任何书籍内容；通过书源获取的正文来自第三方网站，版权归原作者所有。
