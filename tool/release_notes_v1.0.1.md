## 🌸 樱读 v1.0.1

> 在樱花树下，慢慢读完一本书。

从 1.0.0 以来的第一个更新版，带来五项新功能。最实用的是这一个 —— **以后可以在应用里直接检查更新了**。

---

### 📲 下载

- **APK**：`SakuraRead-v1.0.1.apk`（arm64，约 36 MB）
- 系统要求：Android 7.0（API 24）及以上

### ✨ 本次更新

#### 🔄 应用内检查更新（新）

不用再手动找安装包了：

- **启动自动检查**：打开应用后会自己看看有没有新版本，有的话弹窗告诉你（不想被打扰可在设置里关掉）
- **更新公告**：弹窗里会写清楚这一版更新了什么，看完再决定要不要升
- **国内镜像提速**：默认从国内镜像下载，有进度条，随时可以取消
- **下载完直接装**：不用跳出去在文件管理器里找安装包
- **设置里能手动检查**：设置 → 检查更新；失败可以点重试，已是最新也会明确告诉你

#### 📂 用樱读打开文件（新）

在文件管理器里点开 `.txt` / `.epub` / `.json` 时，现在能选「用樱读打开」了：

- **txt / epub**：自动导入书架并打开阅读
- **json**：识别为书源，自动导入

#### ⚙️ 阅读设置换新样式（新）

以前在阅读界面点设置，弹出的是一长条列表，调字号时常常看不到正文效果。现在改成三个页签：

- **排版 / 外观 / 更多** 分开，找设置更快
- 面板高度收窄，**调字号、页边距时上方正文能一直看见**

#### 📚 书源批量管理（新）

书源多了以后一个个点太慢，现在：

- **长按任意书源**即可进入批量模式
- 支持 **全选 / 批量启用 / 批量停用 / 批量删除**

#### 🔍 单个书源单独操作（新）

点开任意书源能看完整信息，还能：

- **访问网站**：直接在浏览器里打开这个书源对应的站点
- **复制地址**、单个启用或停用、删除

### 🔧 工程

- 新增版本号同步校验，避免「关于」页显示错版本号
- 累计 **255 项自动化测试全部通过**，`flutter analyze` 无问题
