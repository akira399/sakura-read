## 樱读 v1.2.2

本版处理「看着有点卡 / 感觉被锁帧」。

代码里从来没有主动限帧的逻辑（也没有任何 `setFrameRate` 之类的调用）——「卡」来自两处多余的全屏重绘，「锁帧」来自 Android 系统默认显示模式只有 60Hz。这一版把两件事都处理了，并且把帧率浮层做成了开关，方便你自己复测。

### 🌸 不再为装饰动画重绘整页

- 樱花花瓣层原来把整个页面（书架封面、玻璃底栏、所有卡片）包在同一个 `RepaintBoundary` 里，于是**每一帧花瓣动画都要重新栅格化整个页面**。现在花瓣独立成层，动画帧只重绘花瓣自身。
- 花瓣是纯装饰动效，改成 30fps 步进（正文、滚动、翻页仍然按屏幕刷新率出帧），并尊重系统「移除动画」无障碍设置。
- 看板娘立绘与模糊剪影单独成层，呼吸浮动的每帧只做位移合成，不再每帧重跑一次高斯模糊。

实测（MuMu 模拟器，书架静止）：应用 CPU **12% → 7.6%**，Raster 2.4 ms/帧、UI 0.4 ms/帧，无掉帧。

### ⚡ 高刷新率

- 新增「高刷新率」开关（**默认开启**）：通过 `preferredDisplayModeId` 请求屏幕支持的最高刷新率模式，不再被系统默认的 60Hz 钉住。
- 只在同分辨率的模式之间切换，不会顺手改显示尺寸；退出 App 后系统自动恢复，不常驻。
- 屏幕本身只有 60Hz 时不产生任何切换（60Hz 模拟器实测 `want=false`）。

### 📈 排查工具

- 设置 → 性能 → 「显示帧率」：打开 Flutter 性能浮层，实时显示 UI / Raster 每帧耗时与掉帧情况。
- 设置 → 性能 → 「高刷新率」：关掉可回到系统默认模式，更省电。

### 📦 下载

- 手机 / 平板（绝大多数设备）：`SakuraRead-v1.2.2-arm64.apk`（约 48 MB）
- 模拟器 / x86_64 设备：`SakuraRead-v1.2.2-x86_64.apk`

两个包签名一致，可直接覆盖安装旧版本。系统要求 Android 7.0（API 24）及以上。
