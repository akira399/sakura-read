## 樱读 v1.2.2

### 下载

- 手机 / 平板（arm64）：`SakuraRead-v1.2.2-arm64.apk`（约 48 MB）
- 模拟器 / x86_64：`SakuraRead-v1.2.2-x86_64.apk`
- Android 7.0（API 24）及以上，签名一致，可覆盖安装。

### 性能

- 花瓣动画独立成层，不再每帧重绘整页。
- 花瓣动画改为 30fps 步进，正文与滚动仍按屏幕刷新率出帧。
- 花瓣动画尊重系统「移除动画」设置。
- 看板娘立绘与模糊剪影独立成层，浮动只做位移合成。
- 新增「高刷新率」开关，默认开启，按屏幕最高刷新率模式出帧。
- 高刷新率只在同分辨率模式间切换，屏幕本身 60Hz 时不做切换。
- 新增「显示帧率」开关，实时显示 UI / Raster 每帧耗时与掉帧。
- 书架静止 CPU 12% → 7.6%，Raster 2.4 ms/帧、UI 0.4 ms/帧。
- 新增 PerfProbe 调试探针，按 5 秒窗口输出 fps 与耗时统计。
