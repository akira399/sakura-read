## ② 简介版（主推 · 约 120 字）

樱读是一个二次元风格的 Android 阅读器。

本地 TXT / EPUB 直接读，也能导入「阅读 3.0」书源在线搜书、一键换源。

但真正让它不一样的是——书架上住着一位粉发看板娘「小樱」。你读书时她陪在旁边，久不理她会打瞌睡，被惹急了会生气；喂她的点心全部靠阅读时长兑换，她说话的语气也会随着你们的亲密度慢慢变化。

无广告、无账号、完全开源。

---

## ③ 分点版（详情页 / README 用）

### 📖 先把书读好

- **本地通吃**：TXT / EPUB 直接读，TXT 自动识别 GBK 等编码，EPUB 解析目录与封面
- **在线搜书**：兼容「阅读 3.0」书源，多个站点同时搜、结果自动合并，一键换源还保留阅读进度
- **随心排版**：四种翻页动画、六种阅读背景，字号 / 行距 / 字距 / 页边距都能调
- **语音朗读**：按段播报，语速音调可调，读完整章自动接下一章
- **书签与统计**：收藏精彩段落，记录阅读时长、连续天数、读完本数

### 🎀 但你不只是一个人读

- **她一直在场**：全局悬浮的看板娘，拖到屏幕哪儿都跟着你
- **她会回应你**：点一下她会讲话，双击摸摸头，她会害羞
- **她有自己的脾气**：太久不理她，会打瞌睡；反复拖她，会生气（至于哄不哄得回来……）
- **她要吃饭**：樱饼 / 三色团子 / 草莓大福 / 樱花蛋糕，全部靠**阅读时长**兑换，不花钱
- **她会成长**：亲密度共七级，从「初遇」到「挚爱」，台词逐级变化
- **她会捣乱**：你读书的时候，她跑得比平时更欢

### ✨ 其他

- 日系二次元全套皮肤：图标、开屏、书籍封面、空书架都画好了
- 应用内检查更新，国内镜像下载，不必手动找安装包
- 开源 MIT · 无广告 · 无账号 · 本地阅读不需要联网
