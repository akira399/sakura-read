## 樱读 v1.2.5

### 下载

- 手机 / 平板（arm64）：`SakuraRead-v1.2.5-arm64.apk`（约 48 MB）
- 模拟器 / x86_64：`SakuraRead-v1.2.5-x86_64.apk`（约 50 MB）
- Android 7.0（API 24）及以上，签名一致，可覆盖安装。

### 人物（X-Ray）

- 阅读页新增「人物」面板，长按正文里的人名也能打开。
- 列出全书人物、出场次数与出现章节，点片段直接跳到原文。
- 别名自动归并：「西蒙 / 西蒙先生」「马丁 / 老马丁」算同一个人。
- 面板支持搜索人名与别名。
- 可切换「按出场次数 / 按首次出场」排序。
- 人物详情新增「首次出场」一键直达。
- 人物详情新增「常同场」，列出经常一起出现的人并能互相切换。
- 新增「复制人物表」，一键复制成表格。

### 朗读

- 分页模式朗读时会真正翻到正在读的那一页。
- 「语音包」可下载：百变音色（174 人，32 MB）、小雅（14 MB），也可删除。
- 百变音色提供「男声·低沉 / 男声·清亮 / 女声·温和 / 女声·明亮」预设。
- 内置超文语音保留，装好即读，不下载任何东西。
- 新增「AI 分角色朗读」：旁白与对白用不同音调，同一角色全书一致。
- 语速上限从 2.0 提到 3.0。
- 朗读音调可自行调整。

### 书架

- 新增「批量管理」：全选 / 反选 / 多选删除，删除时可同时删本地文件。
- 新增自定义分组，书架顶部出现「全部 / 未分组 / 各分组」筛选条。
- 新增「在屏幕上显示桌宠」总开关，关掉后所有页面都不再出现。
- 书籍详情页改版：目录 / 换源 / 缓存 / 进度四宫格，底部全宽「继续阅读」。

### 数据

- 新增本地备份：一键打 zip（书架、进度、书签、设置、书源、桌宠、统计），列表可恢复。
- 新增 WebDAV 备份：填地址后可直接测试连接、上传、从远端恢复。
- 坚果云改为可用账号直接登录，需要应用密码时会引导到安全选项页。
- 新增「从『阅读』导入」：读取 legado 备份，按书名 + 作者匹配后入架，匹配不到的单独列出。

### 书源 / AI

- 书源搜索并发数可调（默认 8，最高可自定义到 999）。
- 本地模型改为可选清单：Qwen2.5-0.5B / 1.5B / 3B、DeepSeek-R1-Distill-Qwen-1.5B，用哪个下哪个。

### 外观 / 性能

- 新增「磨砂玻璃」开关：阅读页顶栏 / 底栏实时模糊透出正文，默认关闭。
- 开屏动画重做：首帧耗时 227 ms → 5–18 ms，全程稳定 60fps。
- 封面按屏幕宽度解码，首屏绘制更轻。
- 启动时各数据改为并行加载，白屏时间缩短。

### 其它

- 418 项测试通过，`flutter analyze` 无告警。
