## 樱读 v1.2.1

### 下载

- 手机 / 平板（arm64）：`SakuraRead-v1.2.1-arm64.apk`（约 48 MB）
- 模拟器 / x86_64：`SakuraRead-v1.2.1-x86_64.apk`
- Android 7.0（API 24）及以上，签名一致，可覆盖安装。

### 书源规则

- 支持 `text.关键字@href`、`text=关键字`、`text!关键字` 文本选择器。
- 支持 `:contains(文本)`、`:has(子选择器)` 伪类。
- 支持 `!N` 排除索引与负数索引。
- 替换链 `##正则##替换` 支持 `{{变量}}`，正则段与替换段同时生效。
- 非法正则按字面量降级匹配。
- 支持 `<js>…</js>CSS`，跳过 JS 段求值其后规则。
- 列表项自身即 `<a>` 时，`a@href` 正常返回。
- JS 书源提示「暂不支持 JS 书源」。

### 抓取

- 手动跟随 301/302/307/308，保留 POST 方法与请求体。
- 请求自动补 `Referer`。
- 目录支持 `nextTocUrl` 连续抓取，上限 10 页，按链接去重。
- 正文支持 `nextContentUrl` 连续抓取并拼接，上限 5 页。

### 正文清洗

- `@html` 结果先转纯文本，`<br>` / `<p>` / `<div>` 转行并还原实体。
- 水印过滤只作用于短行，长行删除行内水印后保留。

### 其它

- 内置离线语音下拉文案改为「内置离线语音（无需安装）」。
- 修复朗读提示中被原样显示的 `**`。
