## 樱读 v1.2.1

本版聚焦**第三方书源兼容性**：按 Legado（阅读 3.x）的规则语义补齐解析与抓取两层的缺口，
导入社区书源后「能搜到、能进目录、能出正文」的比例大幅提升，并对确实无法支持的能力
（JS 书源）给出明确提示。

### 下载

- **手机 / 平板（arm64）**：`SakuraRead-v1.2.1-arm64.apk`（约 48 MB）
- **模拟器 / x86_64**：`SakuraRead-v1.2.1-x86_64.apk`
- 系统要求：Android 7.0（API 24）及以上；可覆盖安装（签名一致，build 号递增）。

### 书源规则解析

- 文本选择器：`text.关键字@href`、`text=关键字`、`text!关键字`。
- 伪类：`:contains(文本)`、`:has(子选择器)`。
- 索引：`!N` 排除式索引、负数索引。
- 替换链 `##正则##替换`：`{{变量}}` 在正则段与替换段都生效；非法正则按字面量降级。
- `<js>…</js>CSS`：丢弃 JS 段，对其后的 CSS 规则求值。
- 列表项自身匹配：`bookList` 取到的元素本身即为 `<a>` 时，`a@href` 不再返回空。
- JS 书源：错误信息明确写「暂不支持 JS 书源」，不再表现为「无效的地址」或空结果。

### 抓取

- 手动跟随 301/302/307/308，**保留 POST 方法与请求体**（默认行为会退化成 GET 并丢 body）。
- 自动补 `Referer` 为书源站点地址。
- 目录分页：`nextTocUrl` 连续抓取（上限 10 页，按链接去重）。
- 正文分页：`nextContentUrl` 连续抓取（上限 5 页）并拼接。

### 正文清洗

- `@html` 结果先做 HTML→纯文本归一化（`<br>` / `<p>` / `<div>` 转行，还原 `&nbsp;` 等实体）。
- 水印过滤只作用于短行；长行就地删除行内水印，避免整章被判为广告行而丢弃。

### 其它

- 内置离线语音下拉文案改为「内置离线语音（无需安装）」。
- 修复朗读不可用提示里会被原样显示的 `**` 标记。

### 验证

- 单元测试 338 项全部通过；`flutter analyze` 无告警。
- 以 yckceo 书源仓库（id 1298，15 源）做真实网络基准：4 个源「搜索 → 目录 → 正文」
  全通（v1.2.0 为 1 个），5 个 JS 书源给出明确提示，其余为站点失效或规则与站点结构不符。
