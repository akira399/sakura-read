## 樱读 v1.2.4

### 下载

- 手机 / 平板（arm64）：`SakuraRead-v1.2.4-arm64.apk`（约 48 MB）
- 模拟器 / x86_64：`SakuraRead-v1.2.4-x86_64.apk`
- Android 7.0（API 24）及以上，签名一致，可覆盖安装。
