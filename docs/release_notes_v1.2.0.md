## 樱读 v1.2.0

### 下载

- 手机 / 平板（arm64）：`SakuraRead-v1.2.0-arm64.apk`（48.5 MB）
- 模拟器 / x86_64：`SakuraRead-v1.2.0-x86_64.apk`（50.2 MB）
- Android 7.0（API 24）及以上，签名一致，可覆盖安装。

### AI 阅读助手

- 书架右上角与书籍详情页新增 AI 入口。
- 支持 OpenAI Chat Completions 兼容接口，内置 OpenAI / DeepSeek / Kimi / Ollama 预设。
- 可把藏书、在读进度、近 7 天阅读时长作为上下文。
- 流式输出，可中途停止，错误文案为中文。

### 本地小模型

- 设置 → AI 助手新增「内置本地模型」，端侧运行 Qwen2.5-0.5B-Instruct（q8，521 MB）。
- 模型下载依次回退 modelscope / hf-mirror / huggingface，带进度与断点续传。
- 可删除已下载模型，首次加载约 8 秒。

### 内置离线语音

- 随包内置 sherpa-onnx + VITS「超文」中文音色（约 20 MB）。
- 系统引擎不可用时自动接管，完全离线。
- 合成在独立 isolate 运行，播放走原生 MediaPlayer。
- 跟读、自动下一章、语速调节沿用原有逻辑。
- 设置页可手动选中并测试朗读。
- 检测不到系统引擎时提供「去系统设置」按钮。

### 阅读体验

- 滚动阅读支持跨章，滑到底接下一章，往回滑接上一章。
- 目录打开自动定位并高亮当前章。
- 新增音量键翻页，默认开启，仅阅读页内生效。
- 排版页新增段间距滑杆（0–40）。
- 行距下限 1.2 → 1.0。
- 底栏改为透明 + 模糊玻璃效果。
- 正文版心限宽 680，书架列数按屏宽 3~6 列自适应。
- 新增「大封面」书架排列样式。
- 阅读统计新增 7 / 14 / 30 天时长曲线。

### 书籍与导入

- 移除书籍时可勾选同时删除本地文件，弹窗显示路径。
- EPUB 正文图片抽出落盘，滚动阅读显示原图。
- 修复 EPUB 插图缺失。
- 修复文件选择器在桌面端过滤掉全部文件。
- 修复目录识别过于松垮，`0` 不再被识别为章节。
- 修复导入「阅读 3.0」书源后解析不出书籍。
- 修复网络重试的 keep-alive 死连接问题，错误文案改中文。
- JS 脚本生成分类的书源明确标注「暂不支持」。

### 安装包

- 只打 arm64 单架构并压缩原生库，安装包从约 170 MB 降到约 45 MB。
- 新增 52 项测试，累计 322 项通过，`flutter analyze` 无告警。
- README 截图全部重画。
