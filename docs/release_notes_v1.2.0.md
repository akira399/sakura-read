## 樱读 v1.2.0

这一版主要回应评论区那一整轮反馈（12 张截图、16 条意见），并把仓库里挂着的 3 个 issue 全部处理掉。
最值得说的三件事：**能跟小樱聊天了**、**手机没装语音引擎也能朗读了**、**滚动阅读能一章接一章滑下去了**。

### 下载

- **真机 / 大多数手机**：`SakuraRead-v1.2.0.apk`（arm64，48.5 MB）
- **模拟器 / x86_64 设备**：`SakuraRead-v1.2.0-x86_64.apk`（50.2 MB）
- 系统要求：Android 7.0（API 24）及以上
- 已安装旧版可直接覆盖安装（签名一致，build 号递增）

### 新增

**AI 阅读助手「小樱」**（issue #2）

书架右上角与书籍详情页新增 AI 入口，点开就是聊天框。

- 在线接口：兼容 OpenAI Chat Completions，OpenAI / DeepSeek / Kimi / 本地 Ollama 都能接，
  内置预设一键填好地址与模型名
- 懂你的阅读数据：把书架藏书、在读进度、近 7 天阅读时长整理成上下文，
  「我最近读到哪了」这类问题答得出来（可在设置里关掉）
- 流式输出，逐字显示，可中途停止；出错给中文可读提示

**AI 助手可下载「本地小模型」（完全离线）**

设置 → AI 助手 → 运行方式选「内置本地模型」。

- 模型：Qwen2.5-0.5B-Instruct（q8，521 MB，Apache-2.0），用 MediaPipe LLM Inference
  在手机端侧推理 —— 不需要网络，阅读数据不出手机
- 下载走国内镜像：modelscope → hf-mirror → huggingface 依次回退，
  带进度、断点续传、可删除模型文件
- 首次加载约 8 秒（TFLite + XNNPACK 权重缓存），之后秒进；流式吐字

**内置离线语音（TTS）**（反馈：「朗读暂时不可用 · 系统未安装语音合成引擎」）

随包内置一份中文语音模型（sherpa-onnx + VITS 「超文」medium int8，CC0，约 20 MB）。

- 系统引擎全部不可用时自动接管，离线可用、不联网
- 合成在独立 isolate 里跑，不卡界面；播放走原生 MediaPlayer，
  自动跟读、自动下一章、语速调节全部沿用原有逻辑
- 设置页可手动选「内置离线语音 · 小樱（无需安装）」，能当场「测试朗读」
- 检测不到系统引擎时，新增「去系统设置」按钮直接跳到系统文字转语音页面

**阅读时长曲线**（反馈：「如果阅读进度和时间有详细的曲线图」）

「阅读统计」页新增 7 / 14 / 30 天三档曲线，Catmull-Rom 平滑贝塞尔 + 渐变填充 +
今日高亮，不引入第三方图表依赖。

**大封面书架**（反馈：「可以做个这种书架吗」）

排列方式新增「大封面」样式：封面做主视觉、书名作者压在下方，手机一屏 2~3 列，大屏自动多列。

**音量键翻页**（反馈：「音量键翻页」）

音量上 = 上一页、音量下 = 下一页，**默认开启**；只在阅读页内生效，
退出阅读页立刻解绑，不影响系统调音量。

**删除书籍时可同时删本地文件**（反馈：「能不能删除的时候直接删本地文件」）

书架长按 → 移除弹窗新增勾选项，会显示将被删除的路径，默认不勾（防误删）。

**段间距独立调节**（反馈：「行距、段距不能调到负的，间隔还是有点大」）

排版页新增段间距滑杆（0–40），与行距配合可以把版面压得很紧。

**EPUB 正文插图**

导入 EPUB 时把正文引用的图片抽出来落盘，滚动阅读直接显示原图
（分页模式因为按字符测量，仍是「［插图］」占位）。

**宽屏 / 平板适配**（反馈：「能不能适配一下平板啊」）

正文版心最宽 680 逻辑像素，平板上不再一行排 40 多字；书架列数按屏宽自适应（3~6 列）。

### 修复

- **目录每次都要从第一章选**（issue #1）：打开目录自动定位并高亮当前章节，同时滚到当前位置
- **导入「阅读 3.0」书源后出不了书**（issue #3）：`h3@text` 这类**裸标签选择器**
  被拆成两步，导致分类书单永远解析出 0 本；顺带修好「规则改动后列表不刷新」
- **滚动阅读不能跨章**（反馈里呼声最高）：滑到底自动接下一章，往回滑接回上一章，
  向前补内容时补偿滚动位置，视觉上不跳字；进度与页脚章节号同步准确
- **目录识别过于松垮**（`0` 都被当成章节）：不再先 trim 再判缩进、标题长度上限 50 → 32、
  句读过多 / 以句号结尾的行直接否掉
- **底栏「玻璃没效果」**：不透明背景改透明 + `BackdropFilter` 模糊 + 半透明 tint
- **「Connection closed before full header was received」**：keep-alive 死连接被反复重试，
  现在每次重试前重建连接池，重试次数 1 → 2，错误文案改中文
- **EPUB 插图看不到**：用目录标题回填章节时漏传了 `images:`，图片列表被悄悄清空
- **文件选择器在桌面端过滤掉所有文件**：路径解析只认 `/`，Windows 反斜杠路径会整条当文件名

### 变更

- 行距下限 1.2 → **1.0**（再小文字会重叠）
- 音量键翻页默认开启（反馈里被明确点名想要，默认关等于没人发现）
- 安装包瘦身：release 只打 arm64、原生库压缩存储，从三 ABI 的 170 MB 降到 **约 45 MB**
- JS 脚本生成分类的书源明确标注「暂不支持」，不再静默给一个空列表
