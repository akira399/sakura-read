## 樱读 v1.2.3

### 下载

- 手机 / 平板（arm64）：`SakuraRead-v1.2.3-arm64.apk`（约 48 MB）
- 模拟器 / x86_64：`SakuraRead-v1.2.3-x86_64.apk`
- Android 7.0（API 24）及以上，签名一致，可覆盖安装。

### 新手引导

- 引导高亮框与「＋」按钮对齐。
- 书架「＋」上移，不再与底栏「设置」重合。
- 设置页外观按钮同样上移避让底栏。
- 点错两次改为点任意处继续，不会卡在同一步。
- 旁白步骤新增「继续」按钮，不再出现点不动的死路。
- 引导不再触发黑屏彩蛋。

### 桌宠彩蛋

- 彩蛋新增长按 5 秒认错退出。
- 彩蛋 60 秒后自动放行，不再需要重启 App。

### 其它

- 新增 4 项回归测试，348 项测试通过，`flutter analyze` 无告警。
