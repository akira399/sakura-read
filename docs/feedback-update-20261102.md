# 九张截图反馈整理与 1.3.1 处理记录

反馈来源是本次提供的九张社区截图。截图中的评论、广告、作者历史回复均作为参考材料；“已修好”的历史回复不直接作为本次验收证据。截图未提供原始 EPUB、书源 JSON 或故障设备日志，故相应修复使用原创最小样本复现。

| 用户反馈 | 本次方案与实现 | 范围说明 |
| --- | --- | --- |
| 桌宠遮挡、不能关闭 | 设置增加全局开关并持久化；保留阅读时单独隐藏 | 按本次用户补充，默认开启；关闭后各页面均隐藏 |
| 强制引导、互动后锁屏 | 移除桌宠互动触发全屏锁定的路径，禁止根页面拦截返回；引导仅手动启动 | 不再以重启作为退出方式；不新增惩罚性互动 |
| 桌宠动画不连贯 | 保留已有动画，先解决遮挡与强制行为 | 本轮未制作新角色素材和动画帧 |
| EPUB 单本也导入失败，提示 Illegal percent encoding | 容错处理裸百分号路径，避免图片路径重复解码 | 测试包含中文与 `100%` 文件名；未拿到评论原书 |
| EPUB 插图不显示 | 支持 SVG 包裹的 image，处理跨目录同名图片；清缓存后的重建同时恢复插图 | 纯文本分页仍是轻量阅读模式，可切换原书排版查看完整图片 |
| EPUB 排版丢失 | 新增“原书排版（插图与注释）”入口，保留 HTML/CSS/SVG/字体等本地资源 | 禁止脚本和外部网络资源；原书模式按章节保存进度，不保存章内滚动位置；TTS 使用文字模式 |
| EPUB 注释链接弹窗不显示 | 原书模式中截获本地锚点链接，弹出可选中文字的注释面板 | 远程链接阻止访问并提示，避免书内任意外部加载 |
| `1、标题` 无法识别目录 | 在普通章节规则不足时，识别连续的数字加顿号/点号标题 | 要求至少两处且大部分编号连续，减少把列表当目录 |
| 书源搜索慢、希望调整线程 | 并发滑杆 1–32、手动上限 999、单源限时 5–30 秒可设置并保存，增加停止按钮 | 停止后关闭当前搜索客户端；不通过无限重试掩盖失效源 |
| 换源一直转、选源结果错乱 | 限制搜索任务时限；旧详情/分类请求完成后不再覆盖当前选择 | 失效、JS 动态规则及网站拦截仍可能不可用，不宣称兼容全部阅读 3.0 源 |
| 发现页源多难找 | 增加按源名称、分组和网址检索的选择器 | 只列出当前引擎可解析发现分类的已启用源 |
| 简介直接显示 br 标签 | 对简介解析 HTML 后取文本 | 保持简介与书源规则解析分离 |
| 想独立更换封面 | 本地书籍详情增加选择图片作为封面 | 不必为了封面更换正文书源；网络封面下载不再阻塞入架 |
| 自定义字体 | 可导入 TTF/OTF，复制至私有目录，重启时重新加载 | 最大 20 MB，导入失败不替换现有字体 |
| 自定义阅读背景 | 可导入图片并清除；使用低透明度覆盖以保留正文对比度 | 属于文字阅读模式，原书模式使用本地书籍样式 |
| 从源仓库点击不能直接导入 | 接入 `legado://import/bookSource?src=...`，确认后获取 HTTP(S) 订阅 | 不执行订阅脚本；原生链接与粘贴链接均使用同一目标校验 |
| 阅读书架太多，迁移困难 | 支持 bookshelf.json 和包含该文件的备份 ZIP；导入前预览数量，使用最新版导入界面按书名重新匹配书源并获取目录 | 不导入账号或凭据；本地原书必须另行迁移；重复项跳过，匹配失败逐本报告；章内偏移归零 |
| 搜索结果无法加入书架 | 入架后等待落盘并报告错误；封面改为后台补充 | 目录为空时保留明确错误，不伪造空书入架成功 |
| AI 没有正文检索 | 新增无需模型的本地正文关键词检索、出处与章节位置跳转；AI 页支持 `/搜索 关键词` | 仅检索本地 TXT/EPUB 和已缓存在线正文，不上传正文，不伪造联网能力 |
| 希望助手检测失效源 | 新增确定性的书源体检页面，AI 页支持 `/书源体检` | 区分错误与空结果，不根据一次检测自动删除用户书源 |
| 增加随机推荐 | “随便读一本”从未读完的现有书架随机选择 | 采用可解释的本地选书，不让模型编造书目 |
| 下载模型卡住、重试从零开始 | 保留分片，使用 Range/If-Range，核对 Content-Range；支持暂停 | 仅在同镜像且具有资源标识时续传；服务器不支持或资源改变则安全重下 |
| 建议换新小模型 | 保留上游 1.2.5 新增的模型清单与引擎 | 不把评论中的性能数字当事实；模型清单使用上游配置，未新增或替换为评论建议的模型 |
| MultiTTS 无法检测 | Android manifest 增加 TTS_SERVICE 查询声明 | 真正的 MultiTTS 朗读还取决于用户设备安装与引擎配置；本次不安装第三方引擎 |
| 加号与设置重合 | 保留原有 FAB 抬高修复，并运行相关 widget 冒烟用例 | 不重复重做已经生效的布局 |
| 下载链接打不开、朗读音质偏好 | 本次提供可直接取用的本地 APK；保留系统与离线引擎选择 | 社区原链接未给出；不接入评论提及的付费服务或账号 |

## 本轮最小验证

- `flutter analyze --no-pub`：无问题。
- 选定 24 个测试通过：新增反馈用例、解析器、EPUB 图片、FAB 间距与版本一致性。
- Android 包及模拟器验收记录见本次交付说明；模拟器检查采用原创 EPUB/TXT 和本机 HTTP 测试书源。
- 不运行全量回归、不做文件哈希比对，不把单次样本验证表述为全网书源或全部 EPUB 的兼容承诺。
